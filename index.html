How the array works

The program stores student records in a JavaScript array named students.

Each record contains a name and mark. Loops process the array to calculate the average, highest mark, lowest mark, and grade.

Why use an array? It keeps related records together and lets the program process any number of entered students without creating a separate variable for each one.
